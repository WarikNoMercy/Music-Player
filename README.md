# 🎵 Music Player (BluesWaves)

BluesWaves — это веб-приложение для прослушивания музыки, которое позволяет загружать, воспроизводить и управлять музыкальными треками прямо в браузере.

## 🚀 Функциональные возможности

- 📂 **Загрузка файлов** — загружайте любимые музыкальные треки в формате MP3.
- 🎶 **Воспроизведение музыки** — воспроизводите загруженные треки с помощью встроенного аудиоплеера.
- 📜 **Список треков** — просматривайте свои загруженные треки.
- ▶️ **Play** — запускайте музыку прямо из списка треков.
- 🗑️ **Удаление треков** — удаляйте ненужные треки.

## 🛠️ Технологии

Проект построен с использованием следующих технологий:

- **Backend**: Spring Boot (Java)
- **Frontend**: HTML, CSS
- **Веб-фреймворк**: Thymeleaf
- **База данных**: Postgres для хранения информации о пользователях и метаданных музыкальных файлов, Google Drive API для хранения и управления музыкальными файлами
- **Сборка и управление зависимостями**: Maven

## ⚙️ Установка и запуск

### Предварительные требования

Для запуска приложения на локальном сервере вам понадобятся:

- Java 11+
- Maven
- Google API credentials для работы с Google Drive API

### Инструкции по установке

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/WarikNoMercy/blueswaves.git
   
2. Настройте подключение к Google Drive API:

  Создайте проект в Google Cloud Console.
  Включите API Google Drive.
  Создайте OAuth2 credentials и скачайте файл credentials.json.
  Поместите файл credentials.json в корневую папку проекта.
